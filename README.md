# Production API Quality Platform

An evolving software test automation platform built with Python.

This project documents my progression from Python and SQL fundamentals
to API automation, database validation, UI automation, CI/CD,
performance testing, and broader quality-engineering practices.

## Current Focus

Phase 1 — Python Engineering Foundations

- Python fundamentals
- Git and GitHub workflow
- pytest fundamentals
- Clean and maintainable Python code

## Planned Capabilities

- API testing with HTTPX
- REST API validation
- PostgreSQL and SQL validation
- API + database integration testing
- UI automation with Playwright
- Dockerized test environments
- CI/CD with GitHub Actions
- Performance and reliability testing
- Test architecture and maintainability

## Technology Stack

The stack will evolve as the project progresses.

Current:

- Python
- pytest
- HTTPX

Planned:

- PostgreSQL
- psycopg
- Pydantic
- Playwright
- Docker
- GitHub Actions

## Project Philosophy

This is not a collection of tutorial exercises.

The project is developed incrementally to demonstrate practical
software-testing and software-engineering skills.

Each major addition should be understood, tested, documented,
and integrated into the existing project.

## Status

Early development.

The project currently focuses on establishing strong Python,
testing, and engineering fundamentals before introducing more
advanced automation infrastructure.
